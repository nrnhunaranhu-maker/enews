# FRAG.MN — Esport News Website

Монголын esport мэдээний сайтын загвар.

## Файлын бүтэц

```
esport-news/
├── index.html       ← Үндсэн хуудас
├── css/
│   └── style.css    ← Бүх загвар
├── js/
│   └── main.js      ← Interactivity
└── README.md
```

## Функц

- Шар мэдээ / Тиккер
- Hero онцлох мэдээ
- CS2, Dota 2, Valorant, Mobile ангилал
- Шууд тоглолтын скор
- Топ тоглогчийн жагсаалт
- Удахгүй болох тэмцээн
- Хайлт
- Ялгах (filter) товч

## Ашиглах

`index.html` файлыг browser-ээр нээнэ.
Интернэт хэрэгтэй (Google Fonts ачаалахад).

## Өөрчлөх

- `index.html` дотрох мэдээний текст солих
- `css/style.css` дотрох өнгө (CSS variables) солих
- `js/main.js` дотор нэмэлт логик нэмэх
